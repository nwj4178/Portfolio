## Projects

### 01. C언어 테트리스
- **Language:** C
- Console 기반 게임 로직 및 렌더링 구현
- 차분 렌더링, 논블로킹 입력 처리, 배열 기반 충돌 감지

### 02. 화재 감지 AI
- **Language / Framework:** Python / YOLO / PyTorch
- 학습용 데이터셋 구성 및 전처리
- YOLO 모델 파인튜닝 및 하이퍼파라미터 조정

### 03. 스마트 우산 보관함
- **Language / Platform:** C/C++ / Arduino
- 키패드 기반 비밀번호 설정 및 검증
- 릴레이 및 솔레노이드 잠금장치 제어

### 04. 모바일 방치형 클리커 게임

- 재화 및 용사 업그레이드 로직 구현
